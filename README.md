# CSS Learning Journey

Personal practice repository documenting my progress while learning modern CSS.

This repo contains many small experiments and practice files I created while building a solid foundation in CSS. Each file focuses on a specific concept or technique so I can practice and reinforce what I learn.

## Topics Covered

- Selectors, classes, and specificity
- Box model and display types
- Flexbox (alignment, layout, practical demos)
- CSS Grid
- Positioning
- Typography and colors
- Transitions and hover effects
- Animations and keyframes
- Pseudo-classes and pseudo-elements
- Responsive design basics
- Modern CSS techniques and small interactive demos

## Purpose

This is a learning journal focused on consistent daily practice. The goal is to develop strong, practical CSS skills that I can use in real web projects and freelance work.

---

**Note:** File names are descriptive so I can quickly revisit specific techniques later.
